# Wireless Router Configuration

A hands-on networking lab in Cisco Packet Tracer. The activity models a small home network and provides practice configuring a wireless router, connecting wired and wireless clients, and checking their network connectivity.

## Project overview

The simulation is designed around a cable modem, a home wireless router, two wired PCs, and a wireless laptop. It guides the learner through connecting the devices, using the router's web interface, and bringing clients onto the network.

## Practice objectives

- Connect simulated network devices with the appropriate coaxial and Ethernet links.
- Configure basic home-router settings, including its administrative password and DHCP client limit.
- Set a 2.4 GHz wireless network name and WPA2-Personal security.
- Configure clients to obtain IP settings through DHCP and connect a laptop to Wi-Fi.
- Check client addressing and test access to a simulated web destination.

These are the lab's learning objectives; this repository should be presented as a practice activity, not as evidence of a production deployment.

- **Cisco Packet Tracer** — required to open and work through the `.pka` activity.

## How to use

1. Install and open Cisco Packet Tracer.
2. Open the `.pka` activity from this repository.
3. Use the companion HTML worksheet as a guide while completing the simulation.
4. Save your completed work as a separate Packet Tracer file so the supplied activity remains unchanged.

The included worksheet currently shows an **Incomplete** activity status. The README summarizes what the lab is designed to practice; it does not claim that the activity has been completed or that connectivity checks have passed.
